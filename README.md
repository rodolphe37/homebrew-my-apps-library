# Rodolphe37 My-apps-library

## How do I install these formulae?

`brew install rodolphe37/my-apps-library/<formula>`

Or `brew tap rodolphe37/my-apps-library` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "rodolphe37/my-apps-library"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
